# CLAUDE.md

## Branches

- **"main" means `fork` here.** This repo is a fork of acoyfellow/rexweb. All
  of our work lives on `fork`, which is the default branch on GitHub. When asked
  to merge, commit or push "to main", do it on `fork`.
- The real `main` tracks `upstream/main` as a clean mirror. Leave it alone
  unless asked by name to update it from upstream.
- Never push to `upstream`. Its push URL is disabled on purpose.
